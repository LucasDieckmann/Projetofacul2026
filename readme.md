# SENAI - Gestão de Certificados de Treinamento

Sistema para emissão e gestão de certificados de treinamentos de segurança do trabalho (NR-10, NR-35, NR-18, etc.).

## 🚀 Funcionalidades

- Cadastro de turmas de treinamento
- Inserção de participantes em massa
- Geração automática de certificados
- Banco de dados SQLite (local)
- Busca e filtragem de certificados
- Interface responsiva com design SENAI

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- SQLite (sql.js)
